# 多来源人脸录入

目标：在现有人员采集弹窗提供上传照片、Windows 摄像头、板载摄像头三个入口，上传/电脑采集无需开发板在线。通行仍由板载摄像头产生现场特征，后端匹配身份和权限。

设计：保留当前深色界面，在独立 FaceEnrollment 组件内切换来源、选择训练/独立验证/陌生人用途，提供照片预览、逐文件结果及摄像头开启/关闭反馈。登记过程不调用开锁接口。旧照片模式仍沿用原来的样本 API。

后端：新增 image_enrollment.py 和 /api/edge/image-sample。严格解码照片、检测恰好一张正脸，按固件的整数 RGB 灰度、最近邻 160×160、质量门槛、整数均衡化及 4×4 LBPH 参数提取特征，调用同一 FeatureService 保存。保存 source 和照片内容摘要，通过非破坏迁移为旧特征标记 board 来源，拒绝重复照片/特征，保存后使阈值失效。

兼容性：相同算法格式不能保证不同摄像头、Haar/KPU 裁剪的识别距离分布相同。上传图与 Windows 摄像头支持录入，建议用实际板载摄像头另采独立验证；仍需现场误认/拒识评估和同一 ROI 的 C/OpenCV 数值对照。
